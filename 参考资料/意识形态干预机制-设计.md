## 一、HTML 版比 markdown 版强在哪

**强了三点，都是实质性的：**

1. **它自己意识到了"无神论 + 来世"这个问题**。markdown 版没提；HTML 版专门把它标出来当设计难点。
   意识到问题本身就是进步。
2. **它给出了"概念上独立"与"经验上相关"的区分**。表格里那一列"正交性说明与组合可能性"
   是真正有用的做法——它在问"这两根轴会不会一起动"，而不是"它们是不是同一件事"。
3. **它的第 1 条建议就是"不必用上所有维度，选 5-8 个核心滑杆"**。
   这和我上一轮用数据算出来的结论（6 根保留 97.7% 格局）**独立地吻合**。作者的直觉是对的。

## 二、但它对那处"矛盾"的解法是错的（这次我用它自己的例子验证）

原文主张：

> "无神论必然在'世俗'端，'来世'信仰必然在'宗教/传统'端。两者逻辑上无法同时在高位。"
> 并建议：*"通过滑杆范围限制来保证基本逻辑自洽"*。

**用它的六个例子算一下**（`test/ideo-axes-test.js` 第 2 节）：

| 国家 | 神圣↔世俗 | 现世↔来世 | 组合 |
|---|---|---|---|
| 斯大林主义苏联 | 世俗 0.02 | **偏来世 0.95** | ← 世俗 **且** 偏来世 |
| 美国自由主义 | 中等 0.45 | 偏现世 0.08 | |
| 瑞典社会民主 | 世俗 0.08 | **偏来世 0.90** | ← 世俗 **且** 偏来世 |
| 印度尼赫鲁 | 中等 | 中等 | |
| 伊朗神权 | 神圣 0.98 | 偏现世 0.10 | |
| 纳粹德国 | 中等 | 中等 | |

**「世俗 + 偏来世」出现了两次，而且苏联那次正是它的定义性特征**——
"为几代人以后的 Utopia 牺牲当下"，这是世俗的、无神的、但极度未来导向的。

**所以这不是矛盾，是两件事碰巧常常一起出现。** 两轴在数据上的相关是 −0.85（很高），
但那是因为六个样本里**恰好**宗教国家都偏保守、世俗国家都偏进步——
**只有六个样本，无法区分"规律"与"巧合"。**

### 正确的解法

不是加约束禁止这个组合，而是**把两根轴拆成"程度"与"理由"**：

- **保留 `现世↔来世` 作为"程度"轴**：你到底愿意为未来牺牲多少当下。
- **把"为什么"交给别的轴**：宗教的来世（伊朗）、意识形态的来世（苏联）、
  消费主义的现世（美国）——**动机不同，程度可以相同**。
- 于是"无神论 + 高度未来导向"是一个**合法且必须存在**的状态，
  它对应历史上最激进的那类现代化运动。

> 一句话：**HTML 想用一个约束消灭一个"矛盾"，但那个"矛盾"恰恰是它最该建模的对象。**

## 三、真正的风险不在"概念矛盾"，在"推导公式的伪相关"

`test/ideo-axes-test.js` 第 3 节做了个实验：让一个国家的进口依赖度从 0 涨到 1，
看"公有↔私有"和"扩张↔内敛"这两根**概念上完全独立**的轴会怎么动——

| 进口依赖度 | 推得的公有度 | 推得的扩张性 |
|---|---|---|
| 0.00 | 0.00 | 0.05 |
| 0.50 | 0.57 | 0.53 |
| 1.00 | 1.00 | 1.00 |

**相关系数会接近 0.83**：两根轴被同一个原因（依赖度）同时推动。

**这不是设计缺陷，是物理约束。** 在"从世界状态推导"的架构下，
某些轴对必然同向 —— 因为它们共享上游变量。

**所以轴集必须按"实际会不会同向"来裁剪，而不是按"概念上是否独立"来裁剪。**
而这件事**只能靠接入主 sim 后用真实数据回归来发现**——所以它必须是一个测试台，
不能靠设计时的直觉。（这与 vic-toy 主项目那条"量的冲击才留疤"是同一类经验。）

## 四、回答你的问题：干预手段要有，但**不是拨滑杆，是立制度**

你说得对，玩家要能建设理想国度。**维多利亚 3 也确实能"引导"意识形态**——但它不是靠滑杆。
Vic3 的机制是：

> 法律（laws）→ 利益集团（interest groups）的权力结构 → 集团的政治主张 → 再解锁新的法律

**玩家从头到尾没有一根"意识形态滑杆"。** 他改的是**制度**，意识形态是制度的产物。
所以"引导"是真的，只是引导的对象是**机器**，不是**读数**。

### 4.1 两类干预，性质完全不同

| | **立制（Institution）** | **叙事（Rhetoric）** |
|---|---|---|
| 改什么 | 产出意识形态的**机器** | 人们如何**解读**已经发生的事 |
| 成本 | 高，且**有承诺成本** | 低，可随时调整 |
| 可逆性 | **极难反悔** | 随时可改 |
| 失败模式 | 制度与现状不匹配 → 长期低效 | 叙事与现实差距过大 → **反噬** |
| 类比 | 修宪、土改、教改 | 宣传口径 |

**两类都要有，而且必须同时有**——因为它们的失败模式相反：
制度太慢，叙事太快；制度刚性，叙事灵活。
玩家的工作就是**在两边的失败模式之间找平衡**，这就是玩法的骨。

### 4.2 具体的干预清单（每条都对应我们已经有的或已规划的变量）

| # | 干预 | 类型 | 成本 | 可逆性 | 它动的世界变量 → 推导出的轴 |
|---|---|---|---|---|---|
| 1 | **所有权制度**：国有化 / 私有化 / 混合 / 工人自治 | 立制 | 一次性巨额 + 后续效率损失 | 极难 | 国资占比 → ①公有↔私有 |
| 2 | **教育制度**：精英教育 / 普及教育 / 意识形态教育 | 立制 | 持续财政投入 | 难 | 教育投入 + 识字率 → ④体力↔脑力、②个人↔集体 |
| 3 | **用人制度**：意识形态审查 / 专家治国 / 考试取士 | 立制 | 行政成本 + 人才流失 | 难 | 精英构成 → ③等级↔平等 |
| 4 | **承诺机制**：五年计划 / 长期国债 / 宪法条款 | 立制 | 锁定未来预算 | **不可逆** | 投资率 → ⑤现世↔来世 |
| 5 | **联盟制度**：强制同盟 / 不结盟 / 双边条约 | 立制 | 主权让渡 + 被动参战风险 | 难 | 对外依赖结构 → ⑥扩张↔内敛 |
| 6 | **信息制度**：自由媒体 / 审查 / 国家宣传机器 | 立制 | 长期财政 + 国际形象 | 难 | 叙事层方差 ↓ → ④⑤的"宣称 vs 实际"被压缩 |
| 7 | **镇压/容忍**：对异见的处理方式 | 立制 | 短期稳定 + 长期合法性流失 | 中 | 直接压 ②个人↔集体 的实际值 |
| 8 | **叙事口径**：把既成事实说成什么 | 叙事 | 低（但**风险高**） | 随时 | 只动"宣称向量"，不动"实际向量" |

**关键设计**：第 8 项是唯一可以随时调的，而它的风险恰好来自"随时可调"——
**如果你的宣称与实际差距太大，宣传就变成负债**（人们记得你承诺过什么）。
这就把"廉价可逆"变成了一个有代价的选择，而不是一根可以随便拨的滑杆。

### 4.3 玩家实际在玩什么

```
玩家动作                          世界演化                        玩家看到的
─────────                        ─────────                       ─────────
立制度（所有权/教育/承诺…）   →   改变"意识形态的产生机制"    →   六轴向量开始漂移
                                                                    ↓
叙事口径（宣传）              →   改变"人们如何解读现状"      →   宣称向量
                                                                    ↓
                              ←   两个向量的差距 = 不稳定    ←   ★ 张力在这里
```

**"建设理想国度" = 设计一台会产出你想要的那种人的机器，然后生活在它的输出里。**

这比拨滑杆难得多，也诚实得多：

- 你**不能**直接令人民变成集体主义者；
- 你**可以**建国有工厂、办集体农庄、把教育收归国家——**然后等一代人**；
- 而这一代人长大后，他们会形成**他们自己的**意识形态，
  很可能和你要的不一样（因为他们还要吃饭、要过日子）。

### 4.4 怎么让它有"建设感"而不是"被系统玩弄"

三个具体手段：

1. **长周期的可见回报**：制度的效果以"十年"为单位显现，但过程可见
   （受教育人口比例、国资占比、投资率曲线）。玩家的满足感来自**看着机器长成**。
2. **少数"奠基时刻"**：一局里只有 3~5 次机会做**不可逆**的制度选择
   （立国、危机、战后重建）。因为不可逆，所以每次都是真的赌注。
3. **理想国度是可命名的**：把六轴向量映射成一个人能看懂的国家画像
   （"一个世俗的、平等的、为未来牺牲的工业国"），让玩家能指着说"这就是我要的"。
   命名本身就是奖励——这是 Vic3 的对齐感来源。

## 五、修改清单（相对 HTML 版）

| HTML 原设计 | 建议改成 | 理由 |
|---|---|---|
| 15 根滑杆，选 5-8 根做核心 | **6 根，且按"实际相关性"脱耦后定稿** | 12 根里 10 对高相关；6 根保留 97.7% 格局 |
| 加约束禁止"世俗 + 来世" | **允许该组合**，把"为什么未来导向"交给别的轴 | 苏联就是这个组合，禁掉等于禁掉最重要的样本 |
| 滑杆由玩家拨 | **滑杆不可拨**：由制度 + 世界状态推导 | 滑杆=价格类旋钮，会被自愈；且"导向"应通过制度 |
| 玩家干预 = 拨滑杆 | **玩家干预 = 立制（难反悔）+ 叙事（廉价但会反噬）** | 两类失败模式相反，构成真正的取舍 |
| 组合规则用"自动排斥"保证自洽 | **用推导公式的物理约束保证自洽** | 强制排斥会造出世界上不存在的状态 |

## 六、一句话总结

> **你不能拨动意识形态，但你能建造生产它的机器。**
> 这是"建设理想国度"最诚实的版本：你设计制度，制度塑造人，人最后会形成他们自己的样子——
> 而你要和这个结果共存。**这就是冷战，也是"意识工业"这个词真正的分量。**

## 附录：实测（`test/ideo-derive.js` / `ideo-observables.js` / `ideo-shock.js`）

这一轮把"意识形态从世界状态推导"做成了可复跑的测试台，结果比预期更硬——**也推翻了我自己上一轮的乐观结论**。

### 1. 六轴推导第一次尝试：三个公式是坏的

| 轴 | 第一版公式 | 实测结果 |
|---|---|---|
| ① 公有↔私有 | 国家汲取能力 / 总投资 | **方差恰好为 0**（撞死在边界上） |
| ⑤ 现世↔来世 | 投资率（`w.invest` / GDP） | **方差恰好为 0** |
| ② 个人↔集体 | 底层财富 / 均值 | 极差仅 0.04（几乎不动） |
| ③④⑥ | 阶层比 / 建筑比 / 依赖度 | 可用 |

**根因**：`w.invest` 是一个**只增不减的累积器**（只有真的买建筑时才被扣减），
拿它当"资本形成流量"必然溢出。教训与主项目那条一致：**先验量的性质，再写公式。**

### 2. 退一步量原料：14 个观测量的独立性

`test/ideo-observables.js` 把 world 里能读到的量列成表，量了它们自己的方差与两两相关（120 样本）：

```
r=-0.99  底层/均值财富  ×  中层/均值财富
r= 0.96  中层/均值财富  ×  上层/底层财富
r=-0.99  底层/均值财富  ×  上层/底层财富
r=-0.90  工业建筑占比    ×  谷物建筑占比
r=-0.85  底层收支比     ×  进口依赖度
```

**三个阶层财富比之间相关 ±0.96~0.99 → 它们根本不是三根轴，是同一个"分层"维度的三个投影。**

**死掉的原料**（方差 < 0.02，承载不了信息）：国资汲取率（`TAX_RATE` 是常量）、
底层人口占比、中层人口占比（三阶层份额是固定的 78/18/4）。

### 3. 判别实验：这个世界到底有几个自由度？

`test/ideo-shock.js`：给 0 号国一次**量的冲击**（连续 120 个月砍掉一半农场），
看它的六维向量是继续沿原轨迹走，还是拐向新方向。

| | 600→900 月的运动方向（六轴） |
|---|---|
| 对照组 | `[-0.036 +0.001 -0.001 -0.000 +0.053 -0.061]` |
| 冲击组 | `[+0.119 +0.043 -0.079 +0.001 +0.044 -0.060]` |

**方向余弦 = 0.126** —— 向量**确实拐了**，不是只能沿一条轨道跑。
**这证明这个世界有多个自由度**，之前的高相关不是公式的错。

### 4. 但把采样扩到 5 条轨迹后，相关**没有下降**

我原以为"高相关是采样只覆盖一条路径造成的"，于是把采样扩成
3 种子 × 5 条轨迹（基线 / 耕地被毁 / 工业被毁 / 财富被抹平 / 城市化跃升）× 4 时点 × 8 国 = **600 条向量**。

结果：**高相关轴对仍是 6 / 15**（②③ 相关 −0.98、③⑤ 0.87、②⑤ −0.83、①③ −0.78…）。

**所以必须修正上一轮的结论**：
- 冲击造成的"解耦"是**暂时的**——几十年后，①②③⑤ 又都回到同一条工业化-分层轨道上；
- 真正独立的是 **④体力↔脑力（城市化驱动）** 与 **⑥扩张↔内敛（对外依赖驱动）**——
  它们是唯一两个在 600 样本里都不与其他轴高相关的维度。

### 5. 诚实的结论

> **这个模型目前只能干净地支撑 4 根轴，不是 6 根。**
>
> - **1 根**：发展/分层的综合维度（③等级 + ⑤来世 + ①公有化压力 都是它的投影）
> - **1 根**：脑力/城市化（④）
> - **1 根**：对外依赖（⑥）
> - **1 根**：底层相对剥夺（②，但它与③高度耦合，可能只是③的另一种写法）
>
> 轴数**不能超过世界的自由度数**。要多几根真正独立的轴，
> 就必须先给世界多几个**独立驱动**——贸易与封锁、技术换挡、外部冲击、制度差异。
> **这些不是"内容"，是"维度"。** 这与 `开发机制-架构设计.md` 里那条
> "智能体层是世界的镜子"是同一个道理。

**这也把"有限要素"的优先级又提高了一档**：它不只是让地缘政治成立，
它还是给意识形态**增加维度**的前提——没有独立的资源约束，就没有独立的轴。
